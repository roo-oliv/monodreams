## What the reference gif tool's scaling code actually tests
`plan_scale` tests the **factor**, not divisibility: `factor = width / out_width` (or `--scale`), strided path when `factor &gt;= 1.0 and abs(factor - round(factor)) &lt; 1e-9`, output dims by ceil division `-(-width // stride)`; `resample` then does `rgb[::stride, ::stride]` for that path and Pillow `BOX` otherwise. So the code is already the corrected form the issue asks for — it is only the module docstring that says "integer downscales". I worded it as: the whole-factor test is authoritative, quoted the actual predicate, noted ceil division, and called the docstring's phrasing "loose wording for the same thing; the code and its `plan_scale` docstring are the authority".
